# K-패스(모두의카드) 트랙 설계 (2026-08-20)

## 왜
K-패스 환급(교통비의 20~53%)은 카드사 대중교통 혜택(월 3천~1만 원)보다 훨씬 크다. 배지만 붙이면 순위가 환급을 모른 채 매겨져 헷갈린다 → 마일리지처럼 **별도 트랙**으로, 큰 숫자에 환급을 더해 "진짜 받을 돈"을 보여준다.

## 흐름
- 2단계(혜택): 마일리지 스위치 아래 **"K-패스 카드만 볼래요"** 스위치. 켜면 `대중교통·택시` 자동 선택·잠김, 마일리지는 꺼짐. 다른 태그는 계속 고를 수 있다.
- 3단계(사용액): K-패스일 때만 **"그중 버스·지하철비는 얼마예요?"**(프리셋 5/10/15/20만, RULES.transitPresetsMan) + 환급 그룹 타일 4개(일반 20% / 청년 19~34·65세↑·2자녀 30% / 3자녀↑ 50% / 기초·차상위 53%). 교통비 > 사용액이면 경고·막음. 버튼 "K-패스 카드 추천 받기".
- 결과: 칩에 `K-패스`·`교통비 월 N`·`그룹 요율`. 제목 "이런 K-패스 카드가 잘 맞겠어요". 맨 위 `kpassNote` 한 단락(환급 계산식·앱 등록·월 15회·더 받을 수 있음). 카드 큰 숫자 = annualNet + 연 환급, 부제 "K-패스 환급 N + 카드 혜택 최대 M − 연회비", 내역 첫 줄 "🎫 K-패스 환급".

## 계산
- `Query.kpass?: { transitSpend, group }` → `passesFilters`에서 `card.kpass`가 아닌 카드 제외. 나머지(성향 필터·한도·정렬)는 기존 엔진 그대로.
- `kpassMonthlyRefund = transitSpend × RULES.kpassRate[group]` (기본형 정률, **최소치**). 2026-01부터 월 60회·20만 원 상한 폐지(korea-pass.kr FAQ). 정액형·시차출퇴근 시간대(~2026-09-30) 혜택은 더 받는 쪽이라 계산에 안 넣는다.
- 환급은 모든 K-패스 카드가 같으므로 **순위엔 영향 없음**, 표시 금액에만 더한다.

## 데이터
- `Card.kpass?: true` (schema `z.literal(true).optional()`), 32장. 이름에 K-패스가 없는 토스뱅크 체크·케이뱅크 ONE 체크·현대 Z work Edition2·티머니 Pay&GO 신한도 포함.

## 안 한 것 (후속 후보)
- 일반 결과에 "K-패스 환급도 받는 카드예요" 배지/링크.
- 지역 패스(경기·인천·경남·서울 기후동행패스 2026-09) 요율 차이, 선불·모바일 카드 안내(incoming/kpass-prepaid.json), 지역화폐형 5장(regional-hold.json).
