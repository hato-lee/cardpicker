## 제안 (12개 → 15개, 마일리지 트랙 별도 유지)

**분리 (근거 충분):**
1. 카페·편의점 → **☕ 카페** + **🏪 편의점** — 양쪽 다 50장 안팎으로 크고, 한쪽만 주는 혜택이 26개나 됨. "함께 38개"는 혜택 줄을 양쪽에 복제하고 기존 capGroup(통합 한도) 장치로 한도 공유 처리 가능
2. 통신비·OTT → **📱 통신비** + **📺 OTT·구독** — 통신만 24 vs OTT만 11로 성격이 다름. 구독(멤버십) 혜택도 OTT 쪽에 흡수

**이름 정비 (데이터 변경 없음):**
3. 주유 → **⛽ 주유·전기차 충전** — 충전 혜택 9개가 이미 안에 있음. EV 오너가 "주유"를 건너뛰는 문제 해결
4. 온라인 쇼핑 — 유지하되 UI 부제로 "간편결제 포함" 명시

**신설 (재수집 필요):**
5. **🛒 마트·장보기** — 12장 확인 + 카페·편의점 태그에 마트 혜택 8개가 무리하게 끼어 있음. 단, 기존 12태그에 없던 영역이라 수집 때 아예 기록 안 된 카드가 있을 가능성 높음 → 신설하려면 마트 혜택 재수집 필수

**유지:** 모든 가맹점 · 대중교통·택시 · 배달·외식(내부가 배달앱 위주지만 외식 11장은 독립하기엔 얇음) · 병의원·약국 · 학원·교육 · 관리비·공과금 · 해외 결제

## 리스크

1. **수집 편향**: 새 태그 영역은 과거 수집에서 버려졌을 수 있어, 분리·신설 후 "이 카드에 이 혜택이 왜 없지?"가 생길 수 있음 → 분리 태그는 안전(원본이 이미 있음), 신설 태그(마트)만 재수집하면 됨
2. 혜택 줄 복제 시 연 혜택 최대치가 이중 계산되지 않도록 capGroup 필수
3. 태그가 늘면 "질문 3개·1분" 체감이 무거워질 수 있음 — 자주 쓰는 태그를 위로 올리는 정렬로 완화 가능
