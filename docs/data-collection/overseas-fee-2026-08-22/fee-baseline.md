## ③ 권장 기준값

> **보통 카드로 해외 가맹점에서 결제할 때 부담하는 수수료 대표값 = 1.2%** (국제브랜드수수료 1.0% + 해외서비스수수료 0.2%)

근거: 브랜드는 **Master 1.0% = Visa의 하한**이라 낮은 쪽 채택(§0), 카드사분은 **7개 전업사 최빈값 0.20%**(BC 자체 표현 "업계 평균 수준"). 상한 조합(Visa 신형 1.1% + 우리 0.3% = 1.4%)도 하한 조합(신한 1.0 + 0.18 = 1.18%)도 아닌 **보수적 중앙값**이다.

**면제 항목별로 쪼개서 쓴다** — 이게 실제 인코딩 규칙이다:

| 카드가 면제하는 것 | rate |
|---|---|
| 국제브랜드수수료만 | **1.0%** (원문에 Visa 신형 1.1%·Amex 1.4%로 명시되면 그 값) |
| 해외서비스수수료만 | **0.2%** (원문에 0.18·0.25·0.3%로 명시되면 그 값) |
| 둘 다 | **1.2%** |
| 체크카드 해외서비스수수료가 **정액($0.5/건)**인 카드사(하나·우리·NH) | 브랜드분만 세고 정액분은 note (§0 — 건당 결제금액을 가정해야 %가 나온다) |
| JCB·UnionPay 전용 카드의 브랜드수수료 면제 | **넣지 않는다** — 원래 0%인 카드사가 많아 면제해도 실익이 없다 |

## ④ 환율 우대·환전 스프레드를 기준에 넣지 않는 이유

1. **카드사가 %로 공시하는 수수료가 아니다.** 적용 환율(전신환매도율 → 매매기준율) 자체를 바꾸는 것이라 `국제브랜드수수료 1.0%`처럼 원문에서 그대로 인용할 숫자가 없다. §0-2 위반.
2. **통화·은행·시점별 편차가 크다.** 전신환 스프레드는 인기 통화 통상 1% 수준이라지만 비인기 통화는 더 크고, 은행마다 고시가 다르다([은행연합회 외환길잡이](https://exchange.kfb.or.kr/page/on_commission.php) 계열 설명). 주유 1,850원/L처럼 **하나의 고정 기준값을 세울 근거가 없다.**
3. **시점 분모가 어긋난다.** 트래블 체크(하나 트래블로그·신한 SOL트래블)는 선불 충전 구조라 우대가 **결제 시점이 아니라 충전(환전) 시점**에 붙는다. 태그 요율은 "해외 결제 지출액 × rate"인데 우대의 분모는 충전액이다.
4. 결과적으로 트래블카드는 이 조사 이후에도 **환율 우대만큼 여전히 과소평가**된다 → OPEN-ISSUES B-3에 잔여 항목으로 남긴다. (신한 SOL트래블 `환율 100% 우대`, 하나 트래블로그 동일 — note·perks로만 표기)

## ⑤ 해외 ATM 인출 수수료를 태그 요율에 넣지 않는 이유

1. **정액이다.** 건당 **US$3**로 통일돼 있다(KB 체크 현금인출 `건당 US $3`, NH `건당 $3`, 하나 신용 `건당 US$3`, 신한 SOL트래블 면제 문구 `해외 ATM 인출 수수료(건당 $3)`). % 환산하려면 **1회 인출 금액**을 가정해야 한다(§0).
2. **분모가 다르다.** '해외 결제' 태그의 지출액은 **가맹점 결제액**인데 ATM은 **현금 인출액**이다. 엔진은 `태그 지출 × rate`로 계산하므로 섞으면 **카드로만 결제하고 현금은 안 뽑는 사람에게 인출 혜택이 붙는다.**
3. **인출 횟수를 가정할 수 없다.** §2의 "한도 없는 마일리지 추가적립은 순위 계산에서 제외"와 정확히 같은 논리.
4. **현지 ATM 운영사 수수료는 카드사가 면제하지 못한다.** "ATM 수수료 0원" 광고를 그대로 요율화하면 실제 절감액보다 크게 잡힌다.
→ note·perks에만 적는다.

## ⑥ ENCODING-RULES.md §1에 넣을 문단 초안

```markdown
- **해외 수수료 면제 → % 환산은 「국제브랜드수수료 1.0% + 해외서비스수수료 0.2% = 합계 1.2%」 기준** (2026-08-22 결정).
  - 기준선은 **수수료를 그대로 무는 보통 카드**다. 면제 카드는 그만큼 아끼므로 **면제하는 항목만 합산해** rate로 잡는다.
    적립·할인 카드는 수수료를 물면서 적립을 받으므로 **요율에서 수수료를 빼지 않는다** — 기준선에 이미 수수료가 들어있다.
    두 모델은 상대 비교에서 정확히 일치한다: 면제카드(수수료 0·적립 0, 순증 0)를 1.2%로, 적립카드(수수료 -1.2%·적립 1.5%,
    순증 +0.3%)를 1.5%로 잡으면 차이가 그대로 0.3%다.
  - **면제 항목별 요율**: 국제브랜드수수료만 면제 = **1.0%** / 해외서비스수수료만 면제 = **0.2%** / 둘 다 면제 = **1.2%**.
    원문이 브랜드나 요율을 특정하면 그 값을 쓴다(Visa 신형 1.1%·구형 1.0%, Master 1.0%, Amex 1.4%).
    **JCB·UnionPay는 브랜드수수료가 0%인 카드사가 많아 그 면제는 요율로 넣지 않는다.**
  - 근거: 국제브랜드수수료는 Master 1.0%(전 카드사 공통)·Visa 1.0~1.1%(약관 변경 후 신규 상품만 1.1%) → **낮은 쪽 1.0% 채택**.
    해외서비스수수료는 전업 카드사 0.18~0.30%(신한·현대·IBK 0.18 / 삼성·하나·롯데·BC 0.20 / KB 0.25 / 우리 0.30,
    BC 공식 공시 범위는 은행별 0.0~0.35%) → **최빈값 0.20% 채택**.
  - **체크카드 해외서비스수수료가 정액인 카드사(하나·우리·NH = 건당 US$0.5)는 요율에 넣지 않는다** — 건당 결제금액을
    가정해야 %가 나오기 때문(§0). 브랜드수수료분(1.0%)만 잡고 note에 "체크 해외서비스수수료 건당 $0.5 면제는 미반영".
  - **환율 우대·환전 스프레드는 넣지 않는다** — 카드사가 %로 공시하는 수수료가 아니라 적용 환율 자체가 달라지는 것이고,
    통화·은행·시점별 편차가 커 기준값을 세울 근거가 없다(§0). 선불 충전형 트래블 체크는 우대가 결제가 아니라
    **충전(환전) 시점**에 붙어 태그 지출액과 분모·시점이 어긋나기도 한다. note·perks로만 적는다.
  - **해외 ATM 인출 수수료도 넣지 않는다** — 건당 US$3의 정액이고, 태그의 분모(가맹점 결제액)와 다른 지출(현금 인출액)이며,
    인출 횟수를 가정할 수 없다(§2 "한도 없는 추가적립 제외"와 같은 논리). 현지 ATM 운영사 수수료는 카드사가 면제하지 못한다.
    note·perks로만 적는다.
  - 조건은 그대로 살린다 — 브랜드 한정(Master 전용 등)·전월실적·DCC 차단 필요·선불 충전 여부는 note에,
    실적 조건이 카드 minSpend보다 높으면 §3(tiers)으로.
  - `monthlyCap`은 **null**(수수료 면제에는 보통 한도가 없다). 엔진이 월 1만원(RULES.assumedCapWhenUnknown)으로 잘라
    계산하므로 1.2%면 해외 지출 월 83만원까지만 반영된다 — 보수적이라 이대로 둔다.
```

**stars 판정(§8)**: rate 1.2% < 3%, 실제 한도 없음 → 규약 그대로면 **★1**. (엔진 가정한도 1만원을 "cap 5천 초과~1.5만"으로 읽으면 ★2 여지가 있으나, assumedCap은 실제 한도가 아니라 엔진 산물이므로 ★1을 권한다. 하토님 확인 필요.)
