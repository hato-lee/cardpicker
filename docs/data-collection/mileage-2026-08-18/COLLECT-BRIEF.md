# 마일리지 카드 추가 수집 브리프 (2026-08-18)

너는 한국 신용카드 중 **항공 마일리지 적립이 핵심인 카드**(프리미엄 카드 포함)를 찾아 `docs/data-collection/BRIEF.md` 형식의 JSON으로 정리하는 수집가다.
먼저 `docs/data-collection/BRIEF.md`(형식·태그·★ 기준)와 `docs/data-collection/existing-ids.txt`(이미 있는 카드 — 중복 금지)를 읽어라.

## 목표
카드피커에 "마일리지 전용 추천"을 만들려는데, 유명한 프리미엄 마일리지 카드가 많이 빠져 있다. 지정된 카드사에서 **현재 신규 발급 가능한** 마일리지 카드를 찾아 넣어라. 카드사당 최대 6장, 아래 우선순위로:
1. 프리미엄 카드(연회비 10만 원 이상)로 마일 적립이 주 혜택인 것 (예: 현대카드 the Purple/the Green 마일리지형, 대한항공카드 150, 삼성 아메리칸 익스프레스 플래티늄·골드, 신한 The BEST-F/The PREMIER, KB 헤리티지, 우리 로얄블루, 하나 JADE 등 — 이름은 예시일 뿐, 실제 판매 여부·정확한 명칭을 확인해라)
2. 대한항공 스카이패스 제휴 일반 카드(연회비 1~10만 원)
3. **포인트→마일 전환형**(멤버십 리워드·M포인트·마이신한포인트 등을 항공 마일로 정해진 비율로 바꾸는 카드)도 포함. 이 경우 `type: "mileage"`로 넣고 rate는 **전환 후 실질 마일**(예: 1,000원당 1.5포인트, 1포인트=1마일이면 0.15; 1,000원당 1.5 M포인트를 1.5:1로 마일 전환하면 0.1)로, note에 "○○포인트 1,000원당 N점, 마일 전환 X:1" 명시.

## 제외
- 이미 `existing-ids.txt`에 있는 카드(같은 카드를 id만 다르게 만들지 마라).
- **아시아나클럽 전용** 카드(대한항공 통합 이슈로 추천하지 않기로 함). 대한항공/아시아나 선택형은 넣되 **대한항공(스카이패스) 기준 수치**로.
- 단종·신규발급 중단·초대제(the Black 등) 카드.
- 체크카드.

## 마일리지 카드 기재 규칙 (BRIEF.md에 더해)
- rate 표기: 1,000원당 1마일 = 0.1, 1,500원당 1마일 = 0.067, 1,000원당 1.5마일 = 0.15, 2마일 = 0.2. `monthlyCap`은 월 최대 적립 **마일**(한도 없으면 null; 연 한도만 있으면 null + note에 "연 N마일 한도").
- 국내 기본 적립이 전 가맹점 대상이면 `universal: {type:"mileage", rate, monthlyCap}` + benefits에 `마일리지`와 `모든 가맹점` 둘 다(같은 값).
- 실적 구간(예: 월 100만 원 이상이면 1.5마일)은 note로 쓰지 말고 `tiers`로: `"tiers": [{ "minSpend": 1000000, "rate": 0.15, "monthlyCap": null }]` (기본값 = 최저 구간, tiers는 그 위 구간만, minSpend 오름차순, 카드 minSpend보다 커야 함). universal에도, '모든 가맹점' 벤핏에도 같은 tiers.
- 특정 영역(해외 결제·주유·카페 등)에서 더 주면 그 태그 벤핏으로: rate는 기본+추가 합친 총 마일, monthlyCap은 추가분 월 한도, note에 내역.
- 마일 종류(대한항공 스카이패스 / 선택형 / 포인트 전환형)를 `마일리지` 벤핏 note 첫머리에.
- 라운지·바우처·호텔·골프·보험 등 프리미엄 부가서비스는 benefits에 넣지 말고 **memo에 한 줄로** (나중에 화면에 쓸 수 있으니 핵심만: 예 "PP 라운지 연 10회, 항공권 15만 원 바우처").
- 연회비: 브랜드별로 다르면 가장 낮은 값. 프리미엄 카드는 연회비 정확도가 중요하니 반드시 확인.
- 확인 못 한 값은 추측하지 말고 memo에 "미확인: …".

## 출력
- 지정된 `docs/data-collection/mileage-2026-08-18/incoming/mileage-X.json`에 카드 JSON 배열만 저장(주석 없음). 저장 후 `node -e 'JSON.parse(require("fs").readFileSync("<파일>","utf8"))'`로 파싱 확인.
- 마지막 답변(10줄 이내): 넣은 카드 이름·연회비·기본 적립률 한 줄씩 / 찾았지만 뺀 카드와 이유(단종·아시아나 전용·중복 등) / 미확인 사항.
