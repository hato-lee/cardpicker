# 카드피커 마일리지 카드 재검수 브리프 (2026-08-18)

너는 이미 저장된 **항공 마일리지 카드** 데이터(AI 초안)를 공식 정보와 대조해 틀린 값을 고치는 검증가다.
마일리지 카드는 지금 결과가 이상하다는 지적이 있어 **전부 다시 검수**한다. 추측으로 고치지 말고, 확인된 것만 고쳐라. 확인 못 한 것은 "미확인"으로 남겨라.

## 입력
- 지정된 `batch-X.json`: 검증할 카드 배열(현재 저장된 값 그대로). 각 카드의 `memo`에 지난 검증 이력이 있다 — 참고만 하고, 이번엔 **처음부터 다시** 확인한다.

## 도구·순서 (카드 1장당 WebSearch 5회 안에서. 세션 전체 검색 한도가 있다.)
1. `officialUrl`을 WebFetch로 읽는다. 읽히면 1순위 근거.
2. 안 읽히면 WebSearch로 "<카드명> 마일리지 적립 연회비 전월실적" 검색 → 카드사 공식 페이지(모바일 m.xxx 포함) 우선, 안 되면 뱅크샐러드(banksalad.com/product/cards/…)·카드고릴라 상세. 참고 사이트를 쓰면 memo에 "출처: 뱅크샐러드 참고" 명시.
3. 사이트 경험: 신한(shinhancard.com)·KB(m.kbcard.com)·롯데·BC(m.bccard.com) 잘 읽힘 / 삼성 절반 / 현대·하나·NH·우리는 대부분 JS라 뱅크샐러드·카드고릴라 참고. 검색 결과 스니펫도 근거로 쓸 수 있다(memo에 그렇게 적어라).

## 마일리지 카드에서 꼭 확인할 것 (카드마다)
1. **판매 중인가?** 2025~2026년에 스카이패스/아시아나 제휴카드가 여럿 단종됐다. 단종·신규발급 중단이 확실하면 `status: "discontinued"`.
2. `annualFee`(원, 정수. 브랜드별로 다르면 가장 낮은 값, 국내전용 우선), `minSpend`(기본 적립에 필요한 전월실적 원, 없으면 0).
3. **기본 적립률** — `마일리지` 벤핏의 `rate`. 표기 규칙: 1,000원당 1마일 = `0.1`, 1,500원당 1마일 = `0.067`, 1,000원당 1.5마일 = `0.15`, 1,000원당 2마일 = `0.2`. 마일 종류(대한항공 스카이패스 / 아시아나클럽 / 선택형)를 note 첫머리에 적어라. **국내 기본 적립이 전 가맹점 대상이면**(대부분 그렇다) `universal`을 `{ "type": "mileage", "rate": <같은 값>, "monthlyCap": <같은 값> }`로 두고 benefits에 `모든 가맹점`(type mileage, 같은 rate/cap) 항목도 있어야 한다 — 없으면 `set.universal` + `addBenefits`로 추가.
4. **한도** — `monthlyCap`은 월 최대 적립 **마일**(원 아님). 공식적으로 "한도 없음"이면 `null`. 연간 한도만 있으면 12로 나누지 말고 null로 두고 note에 "연 N마일 한도"라고 적어라. 모르는 경우도 null이지만 memo에 "미확인: 월 한도"라고 남겨라.
5. **실적 구간** — "전월 150만 원 이상이면 1,000원당 1마일로 상향" 같은 구간이 있으면 note에 문장으로 두지 말고 `tiers`로 적어라: 기본 rate/monthlyCap은 카드 minSpend부터 적용되는 최저 구간, 그 위 구간은 `"tiers": [{ "minSpend": 1500000, "rate": 0.1, "monthlyCap": null }]` 처럼 minSpend 오름차순(카드 minSpend보다 커야 함). rate는 기본과 다를 때만. `universal`에도 같은 tiers를 넣고 `모든 가맹점` 벤핏에도 같은 tiers를 넣어라(세 곳이 같아야 함). 상위 구간 monthlyCap은 공식적으로 '한도 없음'일 때만 null(모르면 구간 자체를 넣지 마라).
6. **추가 적립 영역** — 해외·주유·카페 등 특정 영역에서 더 주면 그 태그의 벤핏으로: `rate`는 기본+추가를 합친 **총** 적립률(예: 기본 1마일+추가 1마일 = `0.2`), `monthlyCap`은 추가분의 월 한도 마일(없으면 null), note에 "기본 1마일+추가 1마일, 추가분 월 2,000마일 한도" 식으로. 여러 영역이 한도를 공유하면 같은 `capGroup` 문자열.
7. **빠진 큰 혜택**(12개 태그 안, 예: 해외 결제 2마일, 통신비 할인)이 있으면 addBenefits. 태그 밖(라운지·바우처·보험·항공권 할인쿠폰 등)은 memo에만.
8. `officialUrl`이 카드사 공식 도메인 https 상세 페이지인지. 더 정확한 주소를 찾으면 교체(뱅크샐러드·카드고릴라 주소 금지).
9. 이벤트성·기간 한정 혜택은 반영하지 않는다. 상시 기본 혜택만.

## 태그 12개 (정확히 이 문자열만)
`마일리지` · `모든 가맹점` · `주유` · `카페·편의점` · `온라인 쇼핑` · `배달·외식` · `대중교통·택시` · `통신비·OTT` · `병의원·약국` · `해외 결제` · `학원·교육` · `관리비·공과금`
- 해외 결제 수수료 면제만 있으면 rate 0, note에 적고 stars 1. 정액 혜택도 rate 0 + note.
- 같은 카드 안에 같은 tag 두 번 금지.

## ★ 기준
- 마일리지: ★3 = 1,000원당 1.5마일 이상 / ★2 = 1,000원당 1마일 안팎 / ★1 = 그 외(1,500원당 1마일 등).
- 다른 영역: ★3 = 7% 이상이면서 월 한도 15,000원 이상 / ★2 = 3~7% 또는 한도 5,000원 초과~15,000원 / ★1 = 그 외.
- `모든 가맹점`(마일리지형)도 마일리지 기준으로.
- 복잡도(complexity): 1 = 전 가맹점 단일 적립·실적 없거나 낮음 / 2 = 영역 혜택 2~3개·실적 1단계 / 3 = 선택형·실적 구간별·제외 많음.

## 출력: 지정된 `corrections-X.json`에 **패치 배열만** 저장 (JSON, 주석 없음)
카드 1장 = 패치 1개. 고칠 게 없어도 memoAppend는 반드시 넣는다.
```json
[
  {
    "id": "lotte-loca-platinum-mileage",
    "set": { "annualFee": 100000, "minSpend": 0, "lastChecked": "2026-08-18",
             "universal": { "type": "mileage", "rate": 0.067, "monthlyCap": null, "tiers": [{ "minSpend": 1500000, "rate": 0.1, "monthlyCap": null }] } },
    "benefits": [
      { "tag": "마일리지", "set": { "rate": 0.067, "monthlyCap": null, "stars": 1, "note": "대한항공 스카이패스. 국내·해외 1,500원당 1마일",
                                     "tiers": [{ "minSpend": 1500000, "rate": 0.1, "monthlyCap": null }] } }
    ],
    "addBenefits": [
      { "tag": "모든 가맹점", "type": "mileage", "rate": 0.067, "monthlyCap": null, "stars": 1, "note": "전 가맹점 기본 적립(위 마일리지 항목과 동일)",
        "tiers": [{ "minSpend": 1500000, "rate": 0.1, "monthlyCap": null }] }
    ],
    "memoAppend": " 마일리지재검수(2026-08-18): 공식 페이지 대조. 기본 1,500원당 1마일·150만 이상 1,000원당 1마일을 tiers로 이행, universal 추가. 미확인: 월 한도. 출처: lottecard.co.kr"
  }
]
```
- `set`·`benefits`·`addBenefits`는 **바뀐 것만**. 안 바뀌면 키 자체를 빼라. (위 예시는 형식 설명용이며 값은 검증 결과에 따라 달라진다.)
- `set`에 `lastChecked: "2026-08-18"`을 항상 넣어라(아무것도 확인 못 한 경우만 제외).
- 벤핏 필드를 지우려면 `"note": null` / `"tiers": null` / `"capGroup": null`.
- `memoAppend`는 " 마일리지재검수(2026-08-18): "로 시작(앞에 공백 하나). 무엇을 대조했고 무엇을 고쳤는지, 출처를 한 줄로. 못 확인한 항목은 "미확인: …".
- 단종: `"set": {"status": "discontinued", "lastChecked": "2026-08-18"}` + memoAppend에 근거.
- 아무것도 확인 못 하면 set 없이 memoAppend에 " 마일리지재검수(2026-08-18): 확인 실패 — <이유>"만.
